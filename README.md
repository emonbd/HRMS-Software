HR Management System — Ekushey Television Limited

This project is a production HR Management System developed using Visual Basic with MS SQL Server backend to support workforce operations in a 24×7 television broadcasting environment. The system integrates biometric fingerprint attendance devices and implements a structured ETL pipeline to extract, validate, transform, and store attendance logs for reliable reporting.

Core modules include Employee Information, Attendance Management, Leave Management, Roster Scheduling, Appraisal & Disciplinary Records, and Role-Based User Access. The attendance engine intelligently maps logs to employee schedules and determines workday cycles that span across calendar boundaries — critical for shift-based operations.

The system provides departmental reports, total working hour summaries, audit logs, and administrative correction tools.
